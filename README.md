# Nova AI Assistant Platform 🌌

A premium, immersive, and high-intelligence AI assistant platform designed with a **"Deep Space"** aesthetic. The platform features fluid responsive interfaces, micro-animations, atmospheric depth, and sleek glassmorphic overlays to deliver a visionary user experience.

## 🚀 Live Local Demo
To preview and interact with the application locally, visit:
**[http://localhost:8000/index.html](http://localhost:8000/index.html)**

---

## ✨ Features

### 1. **Portal Landing Page (`index.html`)**
- Cosmic entry point showcasing Nova 2.0 capabilities.
- Direct entry paths via "Start for Free" and "Login" options.
- Dynamic Bento Grid highlighting AI competencies: Creative Writing, Code Generation, and Data Analytics.

### 2. **AI Chat Interface (`chat.html`)**
- Recessed interactive chat panel for natural language queries.
- Mock assistant settings allowing model switches (e.g. GPT-5 Omni, Claude 3.5 Sonnet).
- Clean conversation layout with premium visual bubbles and side history panels.

### 3. **Deep Analytics Dashboard (`analytics.html`)**
- Glassmorphic panels visualizing usage history and user performance statistics.
- Direct action hooks for exporting reports or changing view ranges (e.g., Last 30 Days).

### 4. **AI Tools Hub (`tools.html`)**
- Dedicated space housing pre-configured tools for automated tasks, system prompts, and integrations.

## 🎨 Visual Identity & Style Guide

- **Theme**: Dark Space Mode (`#051424` base background).
- **Core Elements**: Translucent glass containers (`background-color: rgba(26, 34, 51, 0.6)`) with `backdrop-filter: blur(16px)` and thin inner-glow borders.
- **Typography**: 
  - **Headlines**: *Hanken Grotesk* (sharp geometry)
  - **Body Copy**: *Inter* (high readability)
  - **Data/Metadata**: *JetBrains Mono* (technical clarity)
- **Palette**:
  - **Primary**: Vibrant Indigo (`#cabeff`) for core actions.
  - **Secondary**: Electric Cyan (`#5de6ff`) for highlights and active status indicators.
  - **Accent**: Amber (`#ffb95f`) for alerts and notifications.

## ⚙️ Local Development Setup

To run this application locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/JYOTHISHMATHI/AI-Powered-Intelligent-Assistant.git
   cd AI-Powered-Intelligent-Assistant
   ```

2. Start a local server (Python 3 is recommended for lightweight execution):
   ```bash
   python -m http.server 8000
   ```

3. Open **`http://localhost:8000/index.html`** in your browser.
